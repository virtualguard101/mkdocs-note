# Page Encryption Module

Cryptographic primitives, the at-rest envelope format, build-time page helpers,
the git filter protocol, and git repository operations behind
[page encryption](../usage/encryption.md) and the `mkdocs-note crypt` commands.

Called from [plugin core](core-api.md) during the build and from the
[CLI](cli-api.md) for `crypt init` / `status` / `check` / `uninstall` and the
hidden filter commands.
