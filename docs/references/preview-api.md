# Link Preview Module

Build-time preview payloads and static asset helpers for [same-site link preview](../usage/link-preview.md).

Called from [plugin core](core-api.md) when `preview_config.enabled` is true. Link path normalization is shared with the graph via `mkdocs_note.utils.links`.
